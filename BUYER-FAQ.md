# Hotel Easy Pass — Buyer FAQ

**Does it make money now?**  
No. It is a pre-revenue digital asset. The current product includes a monetization architecture but no verified revenue is claimed.

**Is it a real app?**  
Yes. It is a browser-based Progressive Web App that can be installed on supported devices and has separate Traveler Pass and Hotel Owner Hub experiences.

**Does it need a server?**  
The current core experience does not require a backend. That keeps the asset inexpensive to operate and makes it easy for a buyer to add a backend later.

**Can it become a real booking platform?**  
Yes, but that requires adding live inventory, booking/deep-link integrations, partner accounts and appropriate backend services.

**Can the buyer rebrand it?**  
The buyer should confirm the final transfer agreement and third-party asset rights, but the source code is structured so the branding and content can be changed.

**Are affiliate links already active?**  
No. The current marketplace links are ordinary outbound links until an approved partner relationship and tracking URLs are connected.

**What is the biggest growth opportunity?**  
Connecting real hotel inventory and owner onboarding while keeping the simple traveler experience.

**How is it transferred?**  
The preferred method is a secure marketplace/escrow transaction followed by GitHub repository transfer and any separately agreed asset transfers.
