# TurnoverOS

TurnoverOS is a mobile-first property turnover workflow for landlords, property managers, cleaners, and maintenance teams.

## MVP
- Properties and units
- Turnover creation
- Phone camera photo evidence
- Local-first inspection records
- Starter inspection checklist
- Task completion tracking
- Turnover completion status
- Installable PWA

## Launch architecture
The MVP is intentionally API-key-free. Data is stored in the browser so a user can test the workflow without a paid backend. The next production phase can add authentication, cloud storage, team accounts, AI vision, notifications, billing, and audit logs.

## Important
Photo analysis in this MVP is a workflow placeholder, not a claim that an AI model has identified damage. Production AI inspection should be added with a vision provider and explicit user review before any report is treated as authoritative.
