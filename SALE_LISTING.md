## What It Is
Hotel Easy Pass is a mobile-first Progressive Web App built to make hotel stays easier for travelers while giving hotel operators a practical companion toolkit.

It is designed as a lightweight, installable web app rather than a heavy SaaS platform. The current build runs primarily in the browser and does not require a hosted database or application server for its core workflows.

## Traveler Features
- Hotel stay dashboard
- Nearby food, gas, groceries and attractions
- Trip budget and tip tools
- Rewards tracking
- Packing checklist and trip notes
- Trip sharing
- Emergency travel shortcuts
- Room photo check-in/check-out documentation
- Installable PWA experience

## Hotel Operator Features

- Promotion and offer drafting

- Guest perks and local recommendations
- Room-condition inspection workflow
- Browser-local product analytics dashboard
- Foundation for future hotel-partner features
