# Hotel Easy Pass Owner — Sale Listing

A standalone, mobile-first hotel operator workspace for organizing property details, guest offer drafts, direct booking links, staff shifts, owner requests and room-condition photo records.

**Included:** Owner PWA, property profile, owner command center with optional browser speech input, staff shift planner, offer drafting, before/after inspection photo records, local analytics dashboard, owner-only server allowlist, health endpoint and smoke tests.

**Not included:** Traveler Pass or traveler billing, hosted PMS integration, published traveler marketplace, live booking inventory, payroll, multi-user authentication or cloud synchronization.

**Launch status:** Source and smoke tests are maintained in the `owner-app` branch. This version stores records locally in the browser. It does not charge subscriptions or claim cloud/team sync. A separate Owner database/auth service and separate Owner Stripe account are future setup requirements.
